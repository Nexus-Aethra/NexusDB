# 修复计划+实施记录: 算术运算符无优先级 (新 P1-8)

> 日期: 2026-10-17 | 对应审计条目: CODE-AUDIT-REPORT-2026-10-16.md 新 P1-8
> 状态: **已完成**

## 1. 问题

UPDATE SET 与 WHERE 常量折叠两侧都是**单层左结合**, 无运算符优先级:
`SET v = v + 2 * 3` 算成 (v+2)*3 — 任何混合运算 UPDATE 都静默写坏数据.
(审计称"WHERE 侧 fold_cond_arith 优先级正确" — 实测两侧同为左折叠, 均已修.)

## 2. 修复

统一为两级优先级 (标准数学约定, `*` `/` 紧于 `+` `-`):
- UPDATE SET 侧 (`parse_update_set_value`): term 层 `atom (('*'|'/') atom)*`
  + expr 层 `term (('+'|'-') term)*`, 各层左结合;
- WHERE 侧 (`fold_cond_arith`): 同构两级常量折叠.
